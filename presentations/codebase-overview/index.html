Codebase overview02

One command moves work from Mac to GPU and back

The Mac owns identity, policy checks, monitoring, and publication. Grid’5000 owns inference.

01

Mac operator

Validate checkout, resolve immutable input, and create durable state.

02

Grid’5000

Select a policy-compliant site and submit a CUDA allocation.

03

Remote runtime

Run the pinned model and write validated batch checkpoints.

04

Mac relay

Read back the export, check it, and publish one Hub commit.

Inference never falls back to the Mac. Ctrl-C stops monitoring only. Checkpoints and remote jobs remain.
Operator entry point: osm-polygon-grid5000 run --scope region --region afghanistan-latest --stage all

Codebase overview04

Sentence generation is deterministic

The split stage turns joined sections into clean, deduplicated sentence rows before labeling begins.

01

Discover

Read the immutable six-table shard set for each region.

02

Join

Connect polygons to Wikipedia and Wikivoyage with integrity checks.

03

Segment

SaT infers boundaries. A conservative residual pass repairs clear punctuation boundaries.

04

Finalize

Trim, deduplicate, hash, validate, and export the stable schema.

Output keeps sentence text, neighbors, document metadata, polygon metadata, coordinates, and content hashes.
Core modules: ingestion, joins, sentences, finalization, and output validation.

Identity mismatch fails closed. Valid checkpoints are reused. Partial work is preserved. Remote jobs are reattached instead of duplicated when evidence says they are active.

Codebase overview07

Safety is enforced at the boundaries

The pipeline refuses unsafe shortcuts before remote work or publication can begin.

  • Policy. Usage-policy checks run before every OAR submission.
  • Storage. Soft-quota headroom is checked. Only managed completed runs can be cleaned.
  • Identity. Source commit, input revision, model, prompt, and batch settings must match.
  • Execution. GPU inference stays on the allocated CUDA node. No Mac fallback.
  • Publication. Schema, hashes, card, and asset allowlist are checked before one Hub commit.
Safety is part of the public contract, not an operator checklist kept outside the code.

Publish

Read back the committed tree and compare bytes, schema, and metadata.

Release contract. sentences.parquet, manifest.json, README.md, and the two PNG assets.
Output and publishing modules own schema, hashes, card equality, and the Hub commit.
